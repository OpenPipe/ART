# ART Multi-Node Progress Log

## Current State

- Objective: deliver production-quality single- and multi-node ART with Monarch control, live typed communication, multi-node Megatron and vLLM, efficient replica routing, and unchanged simple single-node usage. Generalized RL is not a prerequisite.
- Baseline: `base/austin/glm52_cp` at `bc39c128`; implementation branch `austin/monarch_multinode_training`.
- Completed: contracts/research, cross-host Monarch/RDMA/NCCL smokes, owned SkyPilot/SSH bootstrap, typed rollout/trainer execution, source-identical installed callable validation, host-owned packing/RDMA, the opt-in `MegatronBackend(runtime=...)` cutover, a real 8-rank two-node reduced GLM-5.2 optimizer step, native TP8/PP2 vLLM, exact prefix-event routing, transactional model publication, bounded teardown, PP/VPP scheduling, and secure managed distributed inference are committed and validated.
- Active: typed host admission/shared-root preflight, second-pass optimizer generation correctness, rollout-capacity/autotuner integration, fresh reduced-snapshot TP8/PP1-versus-TP8/PP2 parity, two-replica live cache-affinity routing, and combined trainer-PP2/inference-PP2 PP/VPP throughput validation.
- Blocker/risk: no external blocker. Pinned Monarch 0.2 workers are single-attachment resources, so one runtime must own each worker lifecycle. A crash-consistency audit found retention, collective-divergence, and reader/writer races in the first optimizer-generation implementation; it is being corrected before fresh GPU work. The original optimizer-state fixture is intentionally not migrated.
- Next: land and validate minimal host admission, then run fresh inference parity, cache-affinity, short PP/VPP comparisons, and the selected 20-step combined topology with W&B disabled.
- Authoritative state: tracker `project_tracking/art/monarch_multinode_training/project.md` at `21e1686`; source/base commit `bc39c128`; implementation head `b8ed1ca3`; validated checkpoint `scratch/live_distributed_trainer_state_glm52/multinode/models/glm52-multinode-smoke/checkpoints/0001`.
