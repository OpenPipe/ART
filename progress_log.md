# ART Multi-Node Progress Log

## Current State

- Objective: deliver production-quality single- and multi-node ART with Monarch control, live typed communication, multi-node Megatron and vLLM, efficient replica routing, and unchanged simple single-node usage. Generalized RL is not a prerequisite.
- Baseline: `base/austin/glm52_cp` at `bc39c128`; implementation branch `austin/monarch_multinode_training`.
- Completed: contracts/research, cross-host Monarch/RDMA/NCCL smokes, owned SkyPilot/SSH bootstrap and cleanup, typed host/GPU admission including cross-host flock coherence, typed rollout/trainer execution, source-identical installed callable validation, host-owned packing/RDMA, the opt-in `MegatronBackend(runtime=...)` cutover, a real 8-rank two-node reduced GLM-5.2 optimizer step, native TP8/PP2 vLLM, exact prefix-event routing, transactional model publication, bounded teardown, PP/VPP scheduling, secure managed distributed inference, deployed-capacity-aware rollout autotuning, reader-safe crash-consistent optimizer generations, DP-complete serving capabilities, and a clean two-host Monarch 0.5 lifecycle are committed and validated.
- Active: relaunching the trainer as TP4/EP4/PP2 after proving EP1 is the wrong physical topology; PP/VPP throughput, current-head GLM PP fidelity, failure injection, and the explicit one-host runtime follow.
- Blocker/risk: no external blocker. Fresh-process GLM compilation has a dominant synchronous frontend cost that disk-cache hits do not remove, so throughput runs must retain one warm trainer mesh. The first EP1 probe was intentionally stopped after 27:43 because it replicated all 256 experts and could not represent the intended efficient topology. The seeded random reduced GLM checkpoint is bitwise repeatable within TP8/PP1 but has deterministic PP2 MoE/logit drift; current-head transport isolation remains pending.
- Next: run TP4/EP4/PP2 VPP1 and VPP2 for at least ten steady steps, select packed length/VPP from measured throughput and memory, then resolve PP fidelity and complete the live failure/single-node matrix.
- Authoritative state: tracker `project_tracking/art/monarch_multinode_training/project.md` at `21e1686`; source/base commit `bc39c128`; implementation head `b0f13baf`; validated checkpoint `scratch/live_distributed_trainer_state_glm52/multinode/models/glm52-multinode-smoke/checkpoints/0001`; prefix-affinity artifact `scratch/live_validation_20260715/prefix_affinity_fixed2.json`.
